# Dicionário de Dados — Argos Fitness

Este documento apresenta o Dicionário de Dados do Sistema de Gestão de Academia Argos Fitness.

O documento foi elaborado a partir do Diagrama Entidade-Relacionamento (DER) e apresenta a estrutura conceitual e lógica dos dados do sistema.

## Conteúdo

- Modelo conceitual
- Fluxo de dados
- Convenções utilizadas
- Entidades e atributos
- Tipos físicos dos dados
- Chaves primárias (PK)
- Chaves estrangeiras (FK)
- Índices
- Relacionamentos e cardinalidades
- Controle de acesso
- Recomendações relacionadas à LGPD

## Entidades

O dicionário contempla as seguintes entidades:

- PESSOA
- INSTRUTOR
- ALUNO
- TELEFONE
- PLANO
- PAGAMENTO
- TREINO
- EXERCICIO
- TREINO_EXERCICIO
- AVALIACAO_FISICA
- FORNECEDOR
- EQUIPAMENTO
- MANUTENCAO
- ESTOQUE

## Banco de Dados

**SGBD:** MySQL 8  
**Engine:** InnoDB  
**Codificação:** utf8mb4
