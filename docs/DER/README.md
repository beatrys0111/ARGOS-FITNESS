Diagrama Entidade-Relacionamento — ARGOS FITNESS

Sobre o DER

O Diagrama Entidade-Relacionamento (DER) representa a estrutura de dados do sistema ARGOS FITNESS, apresentando as principais entidades, seus atributos e os relacionamentos existentes entre elas.

O modelo foi desenvolvido com base na documentação e nas regras de negócio definidas para o sistema, permitindo representar de forma organizada as informações utilizadas no gerenciamento da academia.

Principais entidades

O modelo contempla entidades relacionadas às principais funcionalidades do sistema, como:

* Pessoa — informações gerais dos usuários cadastrados;
* Aluno — dados específicos dos alunos;
* Instrutor — informações dos instrutores;
* Telefone — números de telefone associados às pessoas;
* Plano — planos oferecidos pela academia;
* Pagamento — registros de pagamentos realizados pelos alunos;
* Treino — treinos associados aos alunos;
* Exercício — exercícios disponíveis para composição dos treinos;
* Treino_Exercício — associação entre treinos e exercícios;
* Avaliação_Física — registros das avaliações físicas dos alunos;
* Fornecedor — fornecedores de produtos e equipamentos;
* Equipamento — equipamentos utilizados pela academia;
* Manutenção — registros de manutenção dos equipamentos;
* Estoque — controle dos itens armazenados pela academia;
* Funcionalidade — funcionalidades disponíveis no sistema;
* Acesso — controle de acesso às funcionalidades;
* Log_Atividade — registro das atividades realizadas no sistema.

Relacionamentos

O DER apresenta os relacionamentos entre as entidades de acordo com as regras de negócio do sistema, incluindo as relações de cadastro, treinamento, pagamentos, estoque, equipamentos, manutenção e controle de acesso.

Também são representadas as especializações definidas no modelo, permitindo demonstrar a relação entre entidades generalizadas e especializadas.

Objetivo do modelo

O objetivo do DER é fornecer uma representação visual da estrutura lógica dos dados do ARGOS FITNESS, facilitando a compreensão das entidades, seus atributos, relacionamentos e regras de organização das informações.

O modelo serve como base para a construção e implementação do banco de dados do sistema.
